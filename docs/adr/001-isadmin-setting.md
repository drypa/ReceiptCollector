# 1. Установка свойства IsAdmin у пользователя

## Статус
Предложено

## Контекст
У нас есть система с тремя микросервисами:
- Backend на Go, где хранятся пользователи и данные
- Telegram бот для взаимодействия с пользователем  
- Analytics сервис на .NET 8

Необходимо определить способ установки свойства IsAdmin у сущности UserEntity.

## Рассмотренные варианты

### Вариант 1: Ручная установка через админский интерфейс
Преимущества:
- Высокий уровень контроля над привилегиями
- Прозрачность процесса назначения администраторов

Недостатки:
- Необходимость разработки интерфейса для управления правами доступа
- Дополнительная нагрузка на разработку и поддержку

### Вариант 2: Автоматическая установка при регистрации через OAuth (Google/Facebook)
Преимущества:
- Простота в реализации 
- Удобство для пользователей

Недостатки:
- Невозможно установить админский статус без определенной настройки
- Небезопасность при использовании OAuth с открытыми правами доступа

### Вариант 3: Установка через API/CLI инструменты (через миграции)
Преимущества:
- Масштабируемость и автоматизация
- Возможность установки из внешних систем управления пользователями

Недостатки:
- Требуется дополнительный инструментарий для установки
- Сложнее в управлении правами доступа на уровне приложений

### Вариант 4: Конфигурационная система (env переменные/конфиги)
Преимущества:
- Простота установки без дополнительного интерфейса
- Удобство для развертывания в различных окружениях

Недостатки:
- Ограниченность управления правами доступа
- Неудобно для изменения после развертывания

## Решение
Рекомендуем реализовать конфигурационную систему с установкой IsAdmin через переменные окружения или отдельный конфигурационный файл.

## Плюсы решения
- Гибкость в управлении правами доступа
- Возможность автоматизации и масштабирования
- Прозрачность процесса назначения прав

## Минусы решения
- Сложность при массовом изменении прав доступа

## План реализации
1. Добавить переменные окружения или файл конфигурации для назначения админских пользователей
2. Реализовать механизм установки IsAdmin по TelegramId

Этот подход обеспечивает гибкость и поддержку различных сценариев использования в зависимости от контекста развертывания.
