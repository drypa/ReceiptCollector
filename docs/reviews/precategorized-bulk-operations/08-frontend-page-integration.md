- **Задача**: docs/plans/precategorized-bulk-operations.md#08-frontend-интеграция-в-страницу-блокировки-контролов-аддитивный-disabled-таблицы
- **Дата**: 2026-11-13
- **Ревью**: раундов - 1, вердикт APPROVED

## Что сделано

Страница `/precategorized` собрала сквозной сценарий массовых операций (ADR-036 §5):
подключён хук `usePrecategorizedBulkOperations` (`onCompleted: refresh` — автообновление
списка после успеха и ошибки делает хук, дублирующих вызовов нет), в шапке рядом с
«Обновить» размещён компонент `PrecategorizedBulkActions` с `onRun={bulk.run}` напрямую
(заметка сводки 07: снимок id берётся в хуке в момент подтверждения диалога). На время
массовой операции (`bulk.isRunning`) полностью блокируются контролы списка — селект
размера страницы, «Обновить», поле поиска, `Pagination` (существующие пропы
`disabled`/`disabledTitle`) и поштучные кнопки строк через новый аддитивный проп
таблицы `disabled` — все с `title`-подсказкой «Дождитесь завершения массовой операции»,
чтобы сводка относилась к набору строк на экране (паттерн блокировок ADR-028 C5).
`bulk.reset()` вызывается при смене страницы, поиска и размера страницы: итог прошлой
операции не относится к новому набору строк.

## Итоги ревью

### Раунд 1 - APPROVED

Blockers нет: блокировки полные (обе массовые кнопки, поштучные кнопки строк, «Обновить»,
размер страницы, поиск, пагинация — с title-подсказками), `onRun={bulk.run}` напрямую,
`reset()` при смене страницы/поиска/размера, сводка относится к набору строк на экране,
проп таблицы аддитивен. Допущения 1–5 приняты ревьюером.

### Допущения и отклонения от текста плана

1. **`reset()` привязан к `useEffect` на `[currentPage, search, pageSize]`**, а не к
   обёрткам обработчиков: покрывает и программные изменения (клампинг страницы хуком
   после опустевания — сводка при этом снимается, что соответствует «смене страницы»),
   и не требует оборачивания `goToPage`/`setSearch`/`setPageSize`. Срабатывание на
   монтировании — no-op (summary/error пусты, setState с тем же значением не рендерит).
   *Принято ревьюером.*
2. **Сырой `search` в зависимостях `reset()` — осознанно** (оговорка ревьюера
   зафиксирована): хук отдаёт `search: searchInput` (значение поля ввода), поэтому
   сводка снимается с первого нажатия клавиши, до debounce-перезагрузки списка.
   Контракт ADR §5 («сводка сохраняется до следующего действия или смены страницы»)
   не нарушен: ввод в поиск — следующее действие администратора. *Принято ревьюером
   с оговоркой.*
3. **`pageSize` добавлен в сброс сводки** по указанию вызывающей стороны («reset() при
   смене страницы/поиска/размера»); план задачи 08 перечислял только
   `currentPage`/`search` — изменение аддитивное и семантически верное (размер меняет
   набор строк на экране). *Принято ревьюером.*
4. **Расположение `PrecategorizedBulkActions` — прямой ребёнок `<header>`** (третий
   flex-столбец рядом с «Обновить»), а не внутри `<div className="controls">`: CSS-блок
   задачи 07 явно проектировал `.bulk-actions` как «колонку в шапке» (кнопки + busy +
   сводка столбцом). *Принято ревьюером.*
5. **Константа `BULK_LOCKED_TITLE` продублирована** в странице и таблице (третья копия —
   в закоммиченном компоненте 07): сведение в общий модуль потребовало бы правки файла
   задачи 07 вне рамок задачи 08. *Принято ревьюером; см. заметку для задачи 10.*

### Оставлено без изменений (с обоснованием)

- Блокировка навигации в сайдбаре/маршрутов — вне объёма задачи (план, «Что НЕ входит»).
- Кнопка «Попробовать снова» в блоке ошибки загрузки не блокируется: при ошибке загрузки
  массовая операция не может идти (кнопки заблокированы `loadError`), конфликта нет.

## Заметки для коммита

Рекомендуемое сообщение коммита:

```text

```

На что обратить внимание при ручной проверке:

- Состав коммита: два компонента, строка статуса в плане и эта сводка. Пересобранный
  `wwwroot/index.html` в коммите быть не должно (откачен). В диффе плана строка
  `07 → committed` — не правка этой задачи (её выставил оркестратор после коммита 07);
  правка задачи 08 — только строка статуса `08`.
- Ручной сценарий (чек-лист задачи 08, dev-стенд): «Подтвердить все» → диалог с
  `items.length` → busy без чисел → сводка → автообновление; во время операции
  недоступны поиск, пагинация, размер, «Обновить» и поштучные кнопки (с title);
  «Отмена» в диалоге — ни одного запроса (DevTools); двойной клик — один запрос;
  пустая страница — кнопки неактивны; при активном поиске payload содержит только id
  отрисованных строк.
