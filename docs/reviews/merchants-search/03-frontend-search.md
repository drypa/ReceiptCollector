# Задача 03 - Frontend `/merchants`: поле поиска, debounce, сброс страницы и проверки UI

- **Задача**: docs/plans/merchants-search.md#задача-03-frontend-merchants-поле-поиска-debounce-сброс-страницы-и-проверки-ui
- **Дата**: 2026-11-16
- **Ревью**: раундов - 1, вердикт APPROVED

## Что сделано
На странице `/merchants` добавлено одно поле поиска по названию и ИНН (лейбл «Поиск:», `type="search"`, плейсхолдер «Название или ИНН»), привязанное к состоянию хука загрузки. Ввод обрабатывается с задержкой (debounce ~300 мс), при изменении поискового запроса и при смене размера страницы выполняется сброс на первую страницу; применённый (trim) запрос передаётся в API, пустое значение не отправляется. Пагинация, счётчик и обновление работают по данным ответа сервера с учётом фильтра; актуальность ответов обеспечивается через `AbortController` и защиту от устаревших ответов. Остальные контролы, таблица, действия с магазинами, пустое состояние и ограничение доступа (только администратор) сохранены без изменений, подсветка совпадений не добавлялась.
