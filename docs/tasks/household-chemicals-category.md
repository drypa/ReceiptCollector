# Новая категория товаров «Бытовая химия»

## Приоритет
medium

## Проблема
Чистящие средства, стиральные порошки, освежители воздуха, средства для посудомоечных машин и т.п. сейчас размазаны по категориям «Товары для дома» (HomeGoods) и «Косметика и гигиена» (CosmeticsAndHygiene). Расходы на бытовую химию не видны отдельной строкой в аналитике, что затрудняет учёт и анализ таких покупок.

## Цель
Отдельная товарная категория «Бытовая химия», доступная во всех местах, где используются категории товаров: ручная категоризация (страница чеков и страница товаров), AI-подсказки (`suggest`) и фоновый precategorization.

## Пользователи
- Пользователи Analytics, вручную категоризирующие товары на страницах чеков и товаров.
- AI-категоризация (предложения категорий и фоновый precategorization) должна учитывать новую категорию.
- Просмотр аналитики по расходам на бытовую химию.

## Сценарий использования
1. Пользователь открывает страницу товаров (или чек) и видит в выпадающем списке категорий новую категорию «Бытовая химия».
2. Категория отображается в новой группе «Для дома» вместе с «Товары для дома», «Бытовая техника», «Мебель».
3. При запросе AI-подсказки для товара вида «Стиральный порошок», «Средство для мытья посуды» AI может предложить категорию «Бытовая химия».
4. Фоновая precategorization может относить подходящие товары к новой категории.

## Критерии приёмки
- [ ] В enum категорий товаров добавлена категория «Бытовая химия» с отображаемым именем «Бытовая химия».
- [ ] В AI-промпте (OpenAiCompatibleAiClient) описана новая категория, AI валидно возвращает её.
- [ ] Новая категория доступна во всех эндпоинтах выдачи списка категорий (страница чеков и страница товаров) — поведение эндпоинтов страницы товаров остаётся аддитивным, контракты страницы чеков не меняются.
- [ ] В UI (выпадающие списки `<select>`) категория отображается в новой группе «Для дома» вместе с «Товары для дома», «Бытовая техника», «Мебель».
- [ ] Группа «Для дома» приходит с бэкенда (источник истины — backend, решение D1 ADR 010 / явный словарь групп ADR 022), фронт не хардкодит.
- [ ] Ручная категоризация товара как «Бытовая химия» сохраняется и отображается корректно.
- [ ] Юнит-тесты: enum/отображаемое имя/группа (CommodityCategoryTests), endpoints (CommodityEndpointsTests), AI-клиент (OpenAiCompatibleAiClientTests) — обновлены и проходят.
- [ ] Существующие тесты Analytics проходят (`cd Analytics && dotnet test`).
- [ ] Ручная проверка в UI: выпадающие списки показывают новую категорию в группе «Для дома»; AI-подсказка на реальном товаре (например, «Мистер Мускул») возвращает «Бытовая химия».

## Edge cases
- Мыло, шампуни, зубная паста и другие средства личной гигиены остаются в «Косметика и гигиена» — не переносятся в новую категорию.
- Уже категоризированные товары НЕ переносятся в новую категорию (миграция существующих данных не требуется).
- Формулировки товаров, ранее попавшие в «Товары для дома», при повторной категорииAI категоризации могут быть отнесены к новой категории — это допустимо; прямой перезаписи нет.

## Уточнения заказчика
- Проблема подтверждена: цель — видеть расходы на бытовую химию отдельной строкой.
- Состав категории: чистящие средства, средства для мытья посуды, освежители воздуха, стиральные порошки, средства для посудомоечных машин, губки и перчатки для уборки, бумажные полотенца и салфетки, мусорные пакеты, средства от насекомых и тому подобное.
- Группировка UI: выбрана новая группа «Для дома» с переносом туда «Товары для дома», «Бытовая техника», «Мебель» и новой категорией.
- Дедлайнов и привязок к релизу нет.

## Зависимости
- Только сервис Analytics (Backend/Bot не затрагиваются — предполагается уточнить у архитектора).
