# Тост вместо модального окна после сохранения категоризации

## Приоритет
medium

## Проблема
После сохранения категоризации commodities в Analytics UI появляется модальное окно «Готово / Сохранено категорий: N». Пользователь обязан дополнительно нажать кнопку, чтобы закрыть его. Это лишний шаг, замедляющий работу: пользователь категоризирует товары пачками и каждый раз застревает на модальном окне.

## Цель
Заменить модальное окно на всплывающий тост, который сам исчезает через 5 секунд, не требуя действий от пользователя для закрытия.

## Пользователи
Пользователи Analytics с полномочиями на категоризацию commodities.

## Сценарий использования
1. Пользователь категоризирует commodities и нажимает «Сохранить».
2. Вместо модального окна появляется тост:
   - при успехе — с зелёным акцентом и текстом «Сохранено категорий: N» (N — фактическое количество сохранённых);
   - при ошибке — с красным акцентом и текстом ошибки.
3. Тост сам исчезает через 5 секунд.
4. Пользователь может закрыть тост раньше вручную — крестиком.
5. Если пользователь сохраняет ещё раз, новый тост появляется вместе с предыдущими — тосты могут накапливаться.

## Критерии приёмки
- [ ] Модальное окно «Готово» после сохранения категоризации больше не появляется.
- [ ] При успешном сохранении показывается тост с текстом «Сохранено категорий: N», где N — количество сохранённых категорий.
- [ ] Тост успеха визуально отличим зелёным акцентом.
- [ ] При ошибке сохранения показывается тост с красным акцентом, отличимый от успеха без чтения текста.
- [ ] Тост автоматически скрывается через 5 секунд.
- [ ] Тост имеет кнопку ручного закрытия (крестик).
- [ ] Несколько тостов могут отображаться одновременно (накапливаются).
- [ ] Изменения затрагивают только место после сохранения категоризации; другие модальные окна Analytics не меняются.

## Edge cases
- Быстрые повторные нажатия «Сохранить» — каждый ответ порождает свой тост, тосты накапливаются без наложений/конфликтов.
- Ошибка сети / сервера при сохранении — показывается красный тост, модальное окно ошибки не возвращается.
- Количество сохранённых категорий = 0 — тост всё равно показывается с корректным текстом.

## Зависимости
- Нет.
