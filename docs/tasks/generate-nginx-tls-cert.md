# Генерация TLS-сертификатов для nginx

## Приоритет
high

## Проблема
nginx-конфиг (`nginx.prod.conf`) ожидает `fullchain.pem` и `private.key` в `/etc/nginx/ssl/certs/`, но текущий скрипт `generate-ssl-cert.sh` генерирует `certificate.crt` и `private.key`. Имена не совпадают, а `fullchain.pem` по стандарту должен содержать цепочку (серверный сертификат + CA). Сейчас скрипт не решает эту проблему вообще — nginx ещё не деплоился на production.

## Цель
Модифицировать `generate-ssl-cert.sh` так, чтобы он генерировал TLS-сертификаты в формате, пригодном для использования nginx.

## Пользователи
Администратор системы, разработчик при деплое/обновлении сертификатов.

## Сценарий использования
1. Запустить `./generate-ssl-cert.sh`
2. Скрипт читает домен из переменной `ANALYTICS_AUTHLINK_BASE_URL` в `.env`
3. Если CA (`root.key`/`root.crt`) отсутствует — генерирует новый. Если существует — переиспользует
4. Генерирует серверный ключ `private.key`
5. Создаёт CSR и подписывает сертификат через локальный CA
6. Конкатенирует серверный сертификат + CA-сертификат в `fullchain.pem`
7. В результате в `ssl/` появляются: `fullchain.pem`, `private.key`, `root.crt`, `root.key`

## Критерии приёмки
- [ ] `fullchain.pem` содержит серверный сертификат + CA в формате PEM
- [ ] `private.key` генерируется (имя совпадает с ожиданием nginx)
- [ ] Домен для SAN берётся из `ANALYTICS_AUTHLINK_BASE_URL`
- [ ] CA не пересоздаётся, если уже существует
- [ ] `nginx.prod.conf` (ожидает `fullchain.pem` + `private.key`) сможет использовать сгенерированные файлы без изменений
- [ ] Санитайзер: старые артефакты (`certificate.crt`, `csr`, конфиги) не остаются в `ssl/` после завершения

## Edge cases
- `ANALYTICS_AUTHLINK_BASE_URL` содержит `http://` или `https://` префикс — нужно извлечь только домен
- CA просрочен или повреждён — скрипт должен обработать ошибку

## Зависимости
- OpenSSL установлен в среде запуска
- `.env` содержит корректную переменную `ANALYTICS_AUTHLINK_BASE_URL`
- Добавить `ANALYTICS_AUTHLINK_BASE_URL` в `.env.example` с комментарием-подсказкой
